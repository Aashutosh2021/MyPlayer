MyPlayer version 3.4 • Instant Online Playback & Deep Catalog Discovery

This milestone update eliminates online playback latency through proactive stream prefetching, unlocks complete artist catalogs, and enhances network resilience with smart caching.

Key Release Highlights:

  • Instant Online Playback: Eliminated noticeable 3-4 second startup delays via proactive visible-item audio stream URL resolution and background cache preheating.
  • Deep Catalog Discovery: Comprehensive YouTube Music scraping unlocking rare, regional, and alternate track variants.
  • Strict Concurrency Throttling: Coroutine semaphores cap concurrent extractions to 3 items to preserve bandwidth and battery life.
  • Search Cache & Offline Tolerance: Cached search queries with TTL to avoid redundant network hits and protect against transient dropouts.
  • Queue Index Synchronization: Fixed playlist skip mismatches and title desynchronization during rapid track hopping.

MyPlayer version 3.3.5 • Resilient Multi-Device Sync Play & Transport Recovery

Targeted release hardening the Sync Play networking layer with automatic socket reconnection, non-blocking accept loops, and real-time visual connection diagnostics.

Key Release Highlights:

  • Continuous Host Accept Loop: Host socket remains permanently open so disconnected clients can seamlessly rejoin rooms without host recreation.
  • Automatic Stream Recovery: If local Wi-Fi drops, clients automatically reconnect and synchronize playback clocks within milliseconds.
  • Live Connection Diagnostics: Visual indicators show current room status, connected peers, and transport health in real time.
  • Sub-Millisecond Clock Sync: Refined NTP-inspired barrier timestamps for tight synchronized playback between devices.
