# Roadmap

The current version of MyPlayer (RC-2) is considered functionally complete for its core mobile use-case: Hybrid local/online playback, intelligent Autoplay, and synced lyrics.

All previous roadmap items regarding the Recommendation Engine, Lyrics integration, UI styling, and Media3 migration have been **completed and integrated**.

## Future Work

If development continues, the following features are targeted for future major versions:

### Expansion & Ecosystem
- **Android Auto Support:** Provide a native car interface for controlling playback and browsing playlists securely while driving.
- **Wear OS Companion App:** A standalone or companion app for smartwatches to control playback and view synced lyrics on the wrist.
- **Desktop Companion App:** A cross-platform desktop application that syncs with the mobile app.

### Features
- **Cross-Device Playback Sync:** Seamlessly transfer the active playback session (including the current position and Up Next queue) between phone, tablet, and desktop.
- **Cloud Backup & Sync:** Back up user settings, custom playlists, and listening history to the cloud.
- **Playlist Sharing:** Generate shareable links for custom hybrid playlists.
- **Home Screen Widgets:** Highly styled, interactive Android widgets for quick playback control.

### UI Polish
- **Advanced Material You Integration:** Optionally allow users to override the default "Clay" color palette with Android 12+ dynamic colors extracted from their wallpaper.
